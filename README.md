# Loot Ledger｜瑪奇分贓帳本

靜態的瑪奇戰利品分帳工具。輸入掉落物、得標者、數量與單價後，會計算每件物品的分攤金額並彙整至結算總覽。

## 使用方式

- 新增物品時，時間會自動帶入今天的日期與目前時間。
- 「得標者」可輸入多位玩家，請用 `+` 或全形 `＋` 分隔，例如 `莉+C+貓+布`。
- 每列按「單價 × 數量」計算總價，再由該列的得標者平均分攤。例：單價 25,000、數量 1、得標者 `莉+C+貓+布`，每人為 `25,000 ÷ 4 = 6,250` Gold。
- 所有分贓明細與近期使用的人名都會自動保存在目前瀏覽器的本機儲存空間；清除瀏覽器網站資料後才會移除。
- Excel 匯出包含數量、單價、總價與每人分攤；也可匯入舊版的「價格」欄位。

## 本機執行

```bash
npm install
npm run dev
```

## 部署 GitHub Pages

推送至 `main` 後，`.github/workflows/deploy-pages.yml` 會自動建置及部署。首次使用時，請到儲存庫的 **Settings → Pages**，將 Source 設為 **GitHub Actions**。

若儲存庫名稱不是 `SharetheSpoils`，請將 `vite.config.js` 中的 `base` 改為 `/<儲存庫名稱>/`。
